## Important semantics

- pitch movement = candidate。glissandoの断定ではない。
- register candidate = F0 discontinuity + 2種類以上のvoice-quality変化。
- local vibrato / modulation = 0.8 s detrended-F0 descriptor。intentional vibratoの断定ではない。
- Praat HNR と autocorrelation HNR は別定義。
- measurement と interpretation を分離する。

## Write-Back Strategy

We observed a non-fast-forward push failure in run `37116031516` when multiple workflows attempted to write results to `main` concurrently. To prevent data loss and ensure safe concurrent writes, all workflows committing artifacts back to `main` now use a shared helper script (`scripts/common/github_writeback.py`).

This strategy enforces:
1. Reconciling against the latest `main` (fetch & rebase) on push failure.
2. Bounded retries for cleanly applying changes.
3. Aborting the rebase and failing the workflow safely on a genuine conflict; the intended write-back paths are uploaded as GitHub Actions artifacts for recovery.
4. No force push.
5. Cheap CI rejects raw `git push` commands in either `.yml` or `.yaml` workflow files.
6. Historical recovery workflows are `workflow_dispatch` only and must never auto-run on a normal push.

- PR #17 introduced the shared helper and conflict artifacts.
