## 2. M6 candidate semantics

### Pitch movement

selected-F0上の持続的・概ね線形な移動を候補として保存する。

- window: 0.30 s
- |slope| >= 200 cent/s
- total change >= 60 cent
- linear-fit R² >= 0.80
- merged eventにも最終条件を再適用
- median selected-F0 confidence >= 0.50

**glissandoの断定ではない。**

### Register transition

候補成立には以下を要求:

1. F0 discontinuity
2. CPPS / Praat HNR / autocorrelation HNR / spectral tilt のうち最低2種類の独立変化

F1/F2/F3、intensity、vibratoは before/after context には残すが、成立条件には使わない。
