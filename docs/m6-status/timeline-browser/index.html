ブラウザ版の指標

F0 / confidence: F0は周期音の高さ、confidenceはその周期をどれだけ安定して拾えているか。母音・歌声・ベース・弦などで安定しやすく、無音、子音、ノイズ、ドラムやパーカッションのアタックでは低下・乱高下しやすい。F0が出ても「人声」とは限らない。
CPPS-like / HNR: どちらも周期的・調波的な構造の強さを見る。母音や持続する有声音・楽器音では上がりやすく、息・摩擦音・ノイズ・打撃音では下がりやすい。CPPS-likeは軽量proxyで、Praat calibrated CPPSと同値ではない。
RMS / spectral tilt: RMSは音量の目安で、無音・静かな区間では低く、ドラムなどのアタックで瞬間的に跳ねやすい。spectral tiltは200–5000 Hzの高域の減り方で、0に近いほど高域が強く、シンバル、ハイハット、歯擦音、鋭いアタックの影響を受けやすい。
Local pitch modulation: 0.8 s窓のF0揺れ幅と3–9 Hzの周期変動。値が大きいとビブラート、しゃくり、グリッサンド、不安定な発声などの候補になるが、F0誤検出でも増えるため単独では断定しない。
Movement / register: timeline-v2の見方に合わせた候補イベントの簡易ブラウザ実装。研究用Python/Praat pipelineの判定そのものではない。
