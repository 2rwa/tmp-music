ブラウザ版の指標

F0 / HNR: FFT自己相関からYIN風のperiod候補を選択。confidenceは周期性の強さを表すブラウザ内推定値。
CPPS-like: log power spectrumの実ケプストラムから周期ピークのprominenceを測る軽量proxy。Praat calibrated CPPSと同値ではない。
Spectral tilt: 200–5000 Hzのlog-frequency / log-power線形回帰の傾き（dB/octave）。解析用PCMは最大24 kHzへ軽量リサンプルする。
Local pitch modulation: 0.8 s窓のdetrended F0 p95−p05と3–9 Hz最大成分。意図的なビブラートを断定しない。
Movement / register: timeline-v2の見方に合わせた候補イベントの簡易ブラウザ実装。研究用Python/Praat pipelineの判定そのものではない。
