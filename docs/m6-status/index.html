What M6 now measures

Voice quality: calibrated Praat CPPS、Praat HNR(cc)、独自autocorrelation HNR、spectral tilt、Praat Burg F1/F2/F3。
M2 integration: stable-target vibrato extent と selected-F0 の pitch movement candidate をM6へ統合。
Pitch movement guard: slope / total-change / R² に加え、イベントの median selected-F0 confidence ≥ 0.50 を必須化。低confidence軌跡を候補から除外する。
Register candidate: F0 discontinuity に加え、CPPS / Praat HNR / autocorrelation HNR / spectral tilt のうち2種類以上の独立変化を要求する。formant・intensity・vibratoは補助情報のみ。

Interpretation limits

このページは測定結果のスナップショットであり、声の良し悪し・歌唱意図・言語や文化の分類を行うものではない。Pitch movement は glissando の断定ではなく候補、register transition も候補検出である。Formant は source separation、F0、歌唱母音の影響を受け得るため、単独で強い解釈をしない。
