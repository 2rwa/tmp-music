Level 2 の意味

CPPS: M6と同じ calibrated Praat PowerCepstrogram を 0.01 s time smoothing / 0.001 s quefrency smoothing したframe系列。segment中央値とは別の連続観察用。
Praat HNR: Harmonicity(cc) 10 ms系列。autocorr HNRはselected-F0に誘導された独自推定で、両者は同一指標ではない。
Local vibrato: 0.8 s窓のdetrended selected-F0 p95−p05と、十分な連続データがある場合の3–9 Hz dominant modulation rate。意図的なビブラートを断定する指標ではない。
Register / movement: Level 1と同じ候補イベント。連続指標が候補前後でどう変わるかを見るための重ね表示。
