読み方

F0 はM2 selected-F0。confidence 0.50未満は薄く表示する。
CPPS / HNR はstable vocal segment全体の代表値なので、連続フレーム値ではない。横線の長さが測定区間。
Vibrato extent はstable segment内の detrended F0 p95−p05。瞬時のビブラート量ではない。
Pitch movement / register はいずれも候補検出。歌唱意図や声区転換を断定するものではない。
