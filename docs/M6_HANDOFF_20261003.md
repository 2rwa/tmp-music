## Pitch movement semantics

- 0.30 s window
- |slope| >= 200 cent/s
- total change >= 60 cent
- R² >= 0.80
- merged eventにも最終条件を再適用
- median selected-F0 confidence >= 0.50

これは **glissando candidate**。歌唱意図を断定しない。

## Register semantics

F0 discontinuity に加え、以下4種から最低2種の独立変化を要求:

- calibrated CPPS
- Praat HNR
- autocorrelation HNR
- spectral tilt

formant / intensity / vibrato は補助contextのみ。
